WHY IT IS ENOUGH

Each cap measurement is a separate wc invocation on a named file, so a single oversized
file cannot hide behind a total. The syntax parse, the matcher sweep, the reconciliation
and the secret gate all record the command, the exit status, and the matching line
count, so none is a bare empty file whose emptiness could be mistaken for a check that
never ran.

WHAT WAS OMITTED

Files owned by concurrent peers, everything under packages/ and script/, and the five
permanently dirty generated bundles were not measured, edited, or staged.

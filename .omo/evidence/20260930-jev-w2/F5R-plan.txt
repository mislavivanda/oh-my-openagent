WHY IT MATTERS
--------------
Every outcome-agreement number is conditioned on a finite observation window: a record that
does not close inside the window is censored with closedBy=timeout and enters no outcome
numerator or denominator. A reader who does not know the window length cannot interpret
censor_reason_timeout, censored_windows, outcome_status_censored, or any coverage figure.

    => the config schema is the only truthful non-record source.
Decision, matching the finding's own fallback instruction: read the value at runtime from
JevCompletionContinuationWireConfigSchema.parse({}).outcome_window_ms and LABEL it as the
config schema default. If the schema default is ever changed, the rendered number follows.
An explicit caveat line states that records carry no window value, so a run configured with
a different outcome_window_ms is not reflected. (The F3 live driver configures 180000, so
this caveat is load-bearing, not decoration.)

the window produces, then the heuristic rates, then the outcome rates.

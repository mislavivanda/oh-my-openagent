Todo 7 error-shape and timeout verification (2026-09-22):

- `APIError` exposes the HTTP status as readonly property `status: number` and the parsed response body as readonly property `body: unknown`. A live injected-fetch probe returning HTTP 401 JSON observed `status === 401` and `body` equal to the parsed nested object.
- `TypeSafeClient.attempt()` sets `timedOut = true` before aborting its internal `AbortController`; when the injected fetch rejected with an `AbortError` from that signal, the installed SDK produced `APITimeoutError` with message `Request timed out after 20ms.`. It is also an `APIConnectionError` subclass, so consumers must test `APITimeoutError` first.
- `retry: { maxRetries: 0 }` makes `retriesLeft` zero on the initial attempt, so HTTP, timeout, and connection failures are thrown without another fetch.

BILLING SOURCE
Official URL: https://docs.typesafe.ai/models
Quoted sentence: "Price: Charged per input token. Output tokens are free. A Btok is a billion tokens and an Mtok is a million tokens."

The budget is therefore sized from measured input tokens, not inferred from request count. The same official page lists Jev 1.13 at $0.042 per million input tokens. Billing units were resolved from the official pricing documentation, not derived from HTTP request count.

WHY IT IS ENOUGH
The injected fetch counted the exact HTTP dispatch made by a real four-question call. The outcome supplied the resolved model, token usage, and end-to-end backend latency. The official pricing page independently establishes the billing basis.

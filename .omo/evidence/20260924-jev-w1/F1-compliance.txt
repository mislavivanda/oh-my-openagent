FINDINGS
--------
1. [REFERRED TO LEAD - plan defect, not executor defect]
   .omo/evidence/20260924-jev-w1/task-19-home-manifest-diff.txt is 0 bytes, so the mandated
   check-2 invocation prints MISSING_OR_EMPTY for it instead of printing nothing.
   Root cause is an irreconcilable contradiction WITHIN the plan itself:
     - Plan line 267 (todo 19 QA, isolation scenario) requires:
       "diff task-19-home-manifest-before.tsv task-19-home-manifest-after.tsv is EMPTY,
        Evidence .omo/evidence/20260924-jev-w1/task-19-home-manifest-diff.txt"
     - Plan line 273 (this F1 row) requires every MANIFEST-listed artifact to satisfy [ -s ].
   An empty diff written to a file IS a zero-byte file. The two clauses cannot both hold for
   this one artifact. The executor satisfied the substantive clause - isolation proven - and
   described the row honestly in the MANIFEST as "Empty recursive real home OMO manifest diff".
   Independently corroborated above: the before/after manifests are byte-identical, so the
   emptiness is real evidence of success, not a missing artifact or a skipped step.
   I did not modify it; fixing evidence content is outside an independent verifier's remit.
   Lead's call: either accept the 0-byte file as the correct rendering of an empty diff, or
   have the executor write an explicit "EMPTY - isolation proven" line into it. Either way
   this is presentation, not substance, and no re-run of todo 19 is warranted.

2. [MEDIUM - wave integrity, outside my six checks but material]
   F2 and F4 both judged sha ccb259ace, which is HEAD^, NOT HEAD a77a82896.
     a77a82896 committed 2026-09-24T19:04:27Z

   low, but the coverage gap is real and only the lead can decide whether F2 and F4 re-run
